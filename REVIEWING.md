# Independent review packet

Review the exact commit, not a screenshot or grant narrative. Run the 17 local tests, then—only on a disposable Docker host—the regtest command in `REGTEST.md`. Check the Compose file and scripts before execution.

Useful review outcomes are: a reproduced pass tied to the commit and environment; a failing test or trace; a protocol mismatch with a precise citation; or a reason the evidence overstates its claim. “Looks good” is less useful than a counterexample.

No endorsement, reference letter, confidentiality, mainnet funds, or production-security opinion is requested. Public findings may be posted to issue #1; sensitive findings should use GitHub private vulnerability reporting.
